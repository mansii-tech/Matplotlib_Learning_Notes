# Matplotlib Learning Notes 📊

## About This Repository

This repository contains my Matplotlib practice work. I created this notebook while learning Python data visualization.

I used a Movies Dataset to practice different types of charts and understand how to visualize data using Matplotlib.

## Topics Covered

In this notebook, I have practiced the following charts:

1. **Line Chart** – To display IMDb ratings of movies.
2. **Vertical Bar Chart** – To show the top 10 movie genres.
3. **Horizontal Bar Chart** – To represent genre counts horizontally.
4. **Scatter Plot** – To explore the relationship between IMDb votes and ratings.
5. **Histogram** – To understand the distribution of IMDb ratings.
6. **Pie Chart** – To display the percentage of top 5 genres.
7. **Box Plot** – To understand the distribution of IMDb ratings.
8. **Area Chart** – To show average IMDb ratings by release year.
9. **Subplots** – To display two charts in one figure.
